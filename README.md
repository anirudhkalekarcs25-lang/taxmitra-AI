# taxmitra-AI
WhatsApp-based multi-agent GST copilot for MSMEs. Send a bill photo or voice note; AI extracts invoice data, flags missing ITC against GSTR-2B, drafts E-Way Bills above ₹50,000, and prepares GSTR-1/3B JSON for owner approval. Built with FastAPI, LangGraph, GPT-4o-mini Vision, Whisper and FAISS
